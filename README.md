# SkyCast Weather

A responsive weather forecast dashboard built with HTML, CSS and vanilla JavaScript.

## Features
- Search weather by city
- Current temperature, feels-like temperature, humidity and wind
- Sunrise and sunset
- 24-hour hourly outlook
- 7-day forecast
- °C / °F toggle
- Browser location support
- Mobile-friendly responsive UI
- No API key required

## Data source
Weather data comes from Open-Meteo and city coordinates come from the Open-Meteo Geocoding API.

## Run
Open `index.html` directly in a browser, or deploy the repository with GitHub Pages / Vercel / Netlify.
